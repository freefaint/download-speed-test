# Download speed test

Приложение на Node.js для замера скорости скачивания. Node.js делает 10 последовательных GET-запросов и полностью читает тело каждого ответа перед следующим запросом.

## Запуск

В каталоге проекта выполните одну команду. Нужен Node.js 20.12.0 или новее. Устанавливать зависимости и создавать `.env` не требуется.

```sh
npm start
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173) и нажмите «Запустить замер». По умолчанию приложение скачивает [тестовый файл на watch.net.ru](https://watch.net.ru/pub/download-speed-test-10m.bin).

Чтобы сменить файл, задайте `DOWNLOAD_URL` в окружении или в `.env`. Пример настроек есть в `.env.example`. Для консольного запуска с произвольным адресом используйте `npm run cli -- https://example.com/large-image.jpg`.

## Результаты

Стрелка показывает текущую скорость в **Мбит/с**. Зелёная дуга с меткой `max` удерживает пик до следующего запуска. Жёлтая дуга с меткой `avg` показывает среднюю скорость по завершённым запросам и обновляется после каждого из них. Шкала заканчивается на 1000 Мбит/с, а численный результат может быть выше. Во время замера виден счётчик завершённых запросов. Кнопка «Остановить» прерывает скачивание. После полного замера выводятся максимальная и средняя скорости. Время запросов, общий объём и скорость в **MiB/s** доступны под «Подробности замера».

Средняя скорость рассчитывается как общий объём тел ответов, делённый на суммарное время запросов. Один MiB равен 1 048 576 байтам, один Мбит — 1 000 000 бит. На каждый запрос отводится до 120 секунд. Один полный замер с файлом по умолчанию скачивает 100 MiB. Результат зависит от сети и нагрузки сервера.
