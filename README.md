# Download speed test

Консольный скрипт на Node.js без внешних зависимостей. Делает ровно 10 последовательных GET-запросов и полностью читает тело каждого ответа перед следующим запросом. Данные обрабатываются потоком, без сохранения файла в память или на диск.

## Запуск

Нужен Node.js 20.12.0 или новее.

```sh
cp .env.example .env
npm start
```

В `.env` задаётся HTTP/HTTPS-адрес файла:

```dotenv
DOWNLOAD_URL=https://watch.net.ru/pub/download-speed-test-10m.bin
```

Можно передать другой адрес аргументом — он имеет приоритет над переменной окружения:

```sh
npm start -- https://example.com/large-image.jpg
```

Переменная `DOWNLOAD_URL` из окружения имеет приоритет над `.env`. Запускайте скрипт из каталога проекта.

## Что измеряется

- Среднее время запроса в миллисекундах: сумма времени 10 запросов / 10.
- Общий объём: сумма байтов тел всех ответов, без HTTP-заголовков.
- Скорость в **MiB/s**: общий объём / суммарное время запросов / 1 048 576. Один MiB равен 1 048 576 байтам.

Время включает получение заголовков и полное чтение тела; вывод в консоль между запросами в расчёт не входит. Перенаправления обрабатываются автоматически. Соединения могут переиспользоваться. Запрашивается несжатый ответ; если сервер всё равно применяет сжатие, fetch считает байты распакованного тела.

На каждый запрос установлен общий таймаут 120 секунд. Ошибка сети, таймаут или HTTP-статус вне 200–299 прерывают запуск с кодом 1; итог для неполного замера не выводится.

Тестовый файл содержит 10 MiB случайных данных и размещён на сервере в `/var/www/pub/download-speed-test-10m.bin`. Один полный запуск скачивает 100 MiB. Результат отражает скорость до конкретного сервера с учётом его нагрузки, задержек сети и накладных расходов HTTP/TLS, поэтому может отличаться от скорости тарифа провайдера.

## Запуск из браузера

После настройки `.env` запустите `npm run web` и откройте [локальную страницу](http://127.0.0.1:4173). Нажмите «Запустить замер». Запросы делает тот же скрипт Node.js, а страница выводит его результаты по мере получения. В веб-режиме адрес берётся из `DOWNLOAD_URL`.

Стрелка показывает итоговую скорость по шкале от 0 до 1000 Мбит/с. Если скорость выше 1 Гбит/с, стрелка остаётся на максимуме, а число под шкалой показывает результат замера.
